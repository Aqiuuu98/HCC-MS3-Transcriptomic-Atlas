# Draft Code Availability for the current PRIVATE repository

Analysis code and selected lightweight frozen source data for the HCC-MS3 study have been uploaded to the PRIVATE GitHub repository [https://github.com/Aqiuuu98/HCC-MS3-Transcriptomic-Atlas](https://github.com/Aqiuuu98/HCC-MS3-Transcriptomic-Atlas). The initial commit is `d91af36c257de082757229c3262e9836387f9b0f` on `main`. The repository is not publicly accessible; access is limited to authorized collaborators. This draft does not claim public code availability. No public GitHub release, Zenodo record or DOI exists. Public release and any archival deposit require separate approval.

The archive documents the Step1–35 analysis route and Figure/Table provenance. Static source, provenance and integrity checks have been completed, including remote verification of the initial 354-file upload. The analyses have not undergone an independent end-to-end rerun. Original Step21 and Step25 producer code remains unavailable; saved frozen outputs and downstream definitions are preserved. Historical environment locks remain incomplete. The Figure S7A artwork–caption mismatch is documented, with an English correction proposal awaiting author approval and formal manuscript synchronization.

Public source datasets are obtained through NCI GDC and GEO under accessions GSE149614, GSE326201 and GSE281759, subject to their applicable access conditions. The 109 large external objects are excluded from Git. Any approved subset of derived objects requires separate rights/access review and a documented archive plan before deposit. Author metadata and code/derived-data licenses remain pending. This text must be reviewed before use in a submitted or public manuscript.
