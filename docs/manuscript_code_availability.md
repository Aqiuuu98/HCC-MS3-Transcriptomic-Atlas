# Code Availability

The analysis code supporting the findings of this study is publicly available at https://github.com/Aqiuuu98/HCC-MS3-Transcriptomic-Atlas.

This statement describes access to analysis code. Source input data remain available through TCGA-LIHC, GEO accessions GSE149614, GSE326201 and GSE281759, and LINCS/L1000. GitHub is not presented as a deposit of the original clinical or raw expression datasets. Large external objects, missing Step21/25 producer code and incomplete historical environment locks are documented separately. No independent end-to-end reproduction, versioned software release or archival DOI is asserted.
